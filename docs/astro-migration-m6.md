# Astro migration M6 verification

Captured: 2026-07-28

Branch: `codex/astro-migration`

M6 switches the repository to a single Astro frontend build and removes the
legacy Vite SPA. Commit `3b499ad` passed the local gate, was uploaded as a
Cloudflare preview version, and was subsequently deployed to production.
On 2026-07-28 the site owner confirmed submission of the sitemap and homepage
in Google Search Console, completing the final external checkpoint.

## Single frontend build

The default lifecycle is now:

```text
npm run dev       → Astro development server
npm run build     → Astro check + Astro static build
npm run preview   → built Astro site
npm run deploy    → Astro build + Wrangler deployment using wrangler.jsonc
npm run deploy:dry → Astro build + Wrangler dry-run using wrangler.jsonc
```

Wrangler continues to bundle `worker/index.ts`, bind the final `dist` as
`ASSETS`, and run Hono first only for `/api/*`, `/share/*`, and `/report/*`.
All repository Wrangler scripts pass `--config wrangler.jsonc` explicitly.
This prevents a stale `.wrangler/deploy/config.json`, previously generated by
the Cloudflare Vite plugin, from redirecting deployment to the removed
`dist/http_scanner` build.

## Removed legacy surface

The removed frontend surface includes:

- the root `index.html`, `vite.config.ts`, and Vite-only TypeScript project;
- `src/main.tsx`, `src/App.tsx`, `src/router.tsx`, and `src/App.css`;
- React-only homepage, header, footer, navigation, 404, scan-section, and
  recent-scans shell components;
- unused starter assets and the unused Radix navigation-menu wrapper.

The following direct dependencies were removed:

- `@cloudflare/vite-plugin`;
- `@posthog/react`;
- `@radix-ui/react-navigation-menu`;
- `@vitejs/plugin-react-swc`;
- `react-router-dom`.

`vite` remains a direct development dependency because Astro, Vitest, and the
Tailwind Vite plugin still use the Vite toolchain.

## TypeScript boundary

`tsconfig.worker.json` previously extended `tsconfig.node.json`. The latter
therefore contained shared Worker compiler options despite being named and
scoped as the Vite-config project. M6 moved those options into the Worker
configuration before deleting the obsolete Node/Vite project.

  `noindex,nofollow`.
- an unknown route returned the custom page with status 404, not the homepage;

### Wrangler dry-run

The first dry-run exposed a stale Cloudflare Vite-plugin deployment redirect:
Wrangler selected `dist/http_scanner/wrangler.json` and its old `dist/client`
assets. The deployment, dry-run, and type-generation scripts now select
`wrangler.jsonc` explicitly, with a regression assertion in
`legacyFrontendRemoval.test.ts`.

After the fix, `npm run deploy:dry`:

- rebuilt the four Astro pages;
- read 29 static files from `dist`;
- bundled 2305.99 KiB (770.43 KiB gzip) of Worker code and assets;
- recognized the D1, R2, `ASSETS`, and environment bindings;
- exited at `--dry-run` without uploading or deploying anything.
